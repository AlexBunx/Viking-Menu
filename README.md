# VIKING — электронное меню

Электронное QR-меню для кафе VIKING (Минск, ул. Карла Маркса, 21).

Демо: https://alexbunx.github.io/viking-menu/

## Что умеет

- Меню на русском и английском
- Сборный заказ: гость отмечает позиции «+», видит итог и показывает экран «Мой заказ» официанту
- Поиск и быстрый переход по разделам
- После 21:00 блюда кухни недоступны для заказа

## Как обновить меню

Все блюда, цены и граммовка лежат в `menu.json`. Фото — в папке `img/`, у блюда в поле `img` указывается имя файла без `.jpg`.

Структура: разделы → группы → позиции.

```json
{"ru": ["Сырники со сметаной и джемом", "описание"], "en": ["Syrniki with sour cream & jam", "description"], "w": "330 г", "p": 22, "img": "syrniki"}
```

У напитков с несколькими объёмами вместо `w` и `p` используется `v`: `[["250 мл", 8], ["350 мл", 9]]`.

## Файлы

- `index.html` — страница меню
- `menu.json` — данные меню
- `img/` — фотографии
